Magnetometer Calibration

This corrects two distortions in the compass:

Hard-iron (offset)

A fixed magnetic bias from nearby steel/magnets that shifts every reading. Removed by centering the sampled sphere (offset = midpoint of each axis' min/max).

Soft-iron (scale)

Ferrous material warps the sphere into an ellipsoid. Removed by rescaling each axis to a common radius (per-axis gain).

How to collect data

  1. Keep the blimp well away from laptops, phones, motors and desks with steel frames.
  2. Click Start Collecting.
  3. Slowly rotate the airframe through every orientation: full turns about all three axes and a few figure-8 motions, so the sensor sees the whole sphere. Aim for ~500+ samples over 20–30 s.
  4. Click Finish & Compute, review the result, then Save to Device.

The device streams raw magnetometer data, so you can recalibrate any time.
